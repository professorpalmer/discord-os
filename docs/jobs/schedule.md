# Schedule deepen

```bash
discord-os schedule --every 1h --channel-id ID prompt text…
discord-os schedule --list
discord-os schedule --list --channel-id ID
```

List shows `next_ms`, `created_by`, enabled, and a prompt preview.
While HOST is Off, overdue schedules produce one Catch-up briefing
(`skipped_while_disarmed`) — see P0d — not a job storm on On.
