# Wave 5 — DRI role SOP (`add brain --role`)

Optional MetaGPT-lite role label on a brain lake. Injected into the compact recall pack only — **not** a second JobPool or multi-agent runtime.

## Usage

```bash
discord-os add brain --channel-id <id> --dri alex --role implementer
# roles: implementer | reviewer | planner
```

Stored as binding metadata `brain_role`. Compact recall pack shows `Role SOP: implementer` under the DRI line.
