# Desk-pack inject story

One CLI inject for a shared-desk channel:

```bash
# After REQUIRE_OPERATORS=1 and Pair×2
discord-os add desk-pack --channel-id ID --realm puppetmaster \
  --wiki-url https://portablellm.wiki/you --wiki-token … \
  --github-token ghp_…
```

Order inside the pack:

1. **realm** — checkout cook bind (SQLite + env map; live on next poll)
2. **memory** — think-tank channel bind
3. **wiki** / **github** (optional) — `.env` writes; **restart the host**

Then dual ask/steer and gate park per [shared-desk-demo](shared-desk-demo.md).

Not a second brain-lake. Not multi-host. CU/docker stay parked.
