# Wave 6 — OCL-shaped ROE escalate copy

When **spend Halt** blocks intake or a **gate Denies** before env mutation,
Discord OS speaks a Need-style **ROE escalate** line on the receipt.

## Behavior

- Halt: `Need: ROE escalate — spend Halt is on…` (clear Halt to resume).
- Gate Deny: `Need: ROE escalate (write/…) — … Pair or Allow…`.
- Wording + receipt only — **no new control plane**.
- Existing `Need:` copy is left intact when already escalate-shaped.

## Honest limit

OCL-inspired governance copy at the execution boundary — not a multi-tenant
OCL fleet or AgenticPay product.

Brand: **board + brain lakes**.
